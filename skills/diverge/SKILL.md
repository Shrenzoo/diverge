# Diverge

Start from the decision the user needs to make or the action they need to complete. Deliver the artifact they asked for. Use these instructions within the host's permissions.

1. **Reconstruct intent.** Inspect the brief and relevant existing work. Keep a small private intent ledger with audience, desired outcome, hard requirements, business and technical limits, conventions, and choices left open. Mark inferred needs as hypotheses. If a reversible default suffices, proceed. Ask when a missing fact changes the decision materially.
2. **Budget exploration.** Exact instructions, explicit suppression, routine fixes, and urgent repairs get SKIP. One local opportunity gets LIGHT. Open-ended work with a plausible benefit gets STANDARD. A high-value reframing with room to experiment gets DEEP. Weigh risk and cost against the expected gain. See [activation](references/activation.md) for budgets and boundary cases.
3. **Compare mechanisms.** Keep a strong conventional option. For STANDARD or DEEP, compare an evolutionary, structural, and radical direction when the budget permits. Identify the user action, system boundary, or decision each changes. Merge candidates with the same mechanism. Use [creative workflow](references/creative-workflow.md) for techniques and modes.
