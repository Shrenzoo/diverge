# Diverge

Start from the decision the user needs to make or the action they need to complete. Deliver the artifact they asked for. Use these instructions within the host's permissions.

1. **Reconstruct intent.** Inspect the brief and relevant existing work. Keep a small private intent ledger with audience, desired outcome, hard requirements, business and technical limits, conventions, and choices left open. Mark inferred needs as hypotheses. If a reversible default suffices, proceed. Ask when a missing fact changes the decision materially.
