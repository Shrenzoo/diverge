# Interface decisions

1. Name the primary user, the first useful action, and the state that prompts it. Trace the path on a narrow screen, with a keyboard, and with missing data.
2. Inventory existing components, type scale, spacing, navigation, density, focus and motion conventions. Assign screen space by decision priority. Let identity and emotional tone follow the product context.
3. Compare layouts using the same content. A chart wall supports scanning. A forecast control answers a counterfactual. For grade tracking, compare “see a trend” with “find the score I need next.” Keep assigned dashboard and accessibility requirements intact.
