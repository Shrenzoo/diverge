# Designing a comparison

For each direction, write a private one-sentence hypothesis: “For this audience, changing this mechanism will improve this outcome because …”. If two differ only in styling, combine them. Stop generating once another idea could not reasonably change the decision or the cap is reached.

| Technique | Procedure | Example functional question |
| --- | --- | --- |
| First principles | Take the named artifact apart into the job, constraints, information, and decisions. Rebuild from the minimum. | Which grade information changes a student's next action? |
